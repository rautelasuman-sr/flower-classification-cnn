# 🌸 Flower Classification Using CNN

This project is a Deep Learning based Flower Classification system developed using Python and TensorFlow. It uses a Convolutional Neural Network (CNN) to automatically classify flower images into five categories: Dandelions, Daisy, Tulips, Sunflowers, and Roses. The model is trained using the TF Flowers dataset, where images are resized and preprocessed before being given to the CNN for learning. After training, the model is saved as `flower_model.keras` and can be used to predict new external flower images. The project demonstrates the complete basic workflow of a Deep Learning image classification system, including dataset preparation, image preprocessing, CNN model training, model saving, and prediction. Technologies used in this project include Python, TensorFlow, Keras, NumPy, Pillow, and GitHub. The project was developed in VS Code as a practical implementation of Deep Learning and image classification.
